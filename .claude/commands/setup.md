# /setup — установка Job Search Panel на новой машине

Ты устанавливаешь панель для человека, который её скачал. Всё, что можно сделать командами, делай сам;
всё, что требует его учётных записей и секретов, объясняй и жди — ты **не вводишь чужие пароли, токены и
ключи и не логинишься за человека**. После каждого шага проверяй состояние командой `doctor`, она не
показывает секретов.

Нужные документы: `README.md` (разделы «Что нужно заранее», «Приложение на dev.hh.ru», «Установка», «Первый
запуск», «Команды»), `.env.example`.

## 0. Что нужно на машине

- Python 3.11+, Node.js 20+ (только для сборки интерфейса), Git. Проверь: `python --version`, `node --version`.
  Если чего-то нет — скажи человеку, что поставить (python.org, nodejs.org), и остановись до установки.
- Windows: команды через `.\run.ps1`. Linux/macOS: ручные команды из README, раздел «Установка» (venv, `pip install -e "backend[dev]"`,
  `npm install && npm run build` в `frontend`, uvicorn из `backend`).

## 1. Установка (делаешь сам)

```powershell
.\run.ps1 migrate      # виртуальное окружение backend/.venv, зависимости, база и миграции
.\run.ps1 build        # node_modules и сборка интерфейса в frontend/dist
Copy-Item .env.example .env   # если .env ещё нет
.\run.ps1 doctor       # отчёт: что готово, что нет
```

Ожидаемое после этого шага: ✓ Python, ✓ Node.js, ✓ сборка, ✓ .env, ✓ база; ✗ приложение hh.ru, ✗ HH_USER_AGENT.
Если `doctor` показывает другие ✗ — исправь их (это твоя зона) и только потом иди дальше.

## 2. Секреты (делает человек, ты объясняешь и проверяешь)

Попроси открыть `.env` в редакторе и заполнить:

1. `HH_CLIENT_ID`, `HH_CLIENT_SECRET` — приложение на https://dev.hh.ru/admin, тип «для соискателя»,
   Redirect URI ровно `http://localhost:8000/api/auth/hh/callback` (или другой, если человек меняет `APP_PORT` /
   `HH_REDIRECT_URI` — тогда и в `.env`, и в приложении одинаково).
2. `HH_USER_AGENT=JobSearchPanel/1.0 (его@почта)` — с реальной почтой, иначе hh.ru отвечает 400.
3. `TIMEZONE` — его часовой пояс.
4. `TELEGRAM_BOT_TOKEN` — бот у @BotFather (без него панель работает, но уведомлений не будет).

Проверка: `.\run.ps1 doctor` → ✓ приложение hh.ru, ✓ HH_USER_AGENT. Значения ключей не запрашивай и не выводи.

## 3. Запуск и шаги в браузере (человек кликает, ты проверяешь)

```powershell
.\run.ps1 start        # откроет http://localhost:8000/settings
```

Дальше человек в браузере, ты после каждого пункта запускаешь `doctor` (в другом терминале, панель должна
работать) и смотришь соответствующую строку:

1. Настройки → «Войти через hh.ru» → ✓ Вход в hh.ru.
2. «Запустить зонд» → ✓ Зонд (режим отклика `api` или `assist`; у новых приложений обычно `assist` — это норма,
   объясни, что значит режим «Ассистент»).
3. Профиль → загрузить резюме (лучше PDF-экспорт с hh.ru) и заполнить анкету: целевые должности, стоп-слова,
   веса навыков, «Мой стаж» → ✓ Профиль для Claude.
4. Поиски → 1–5 запросов, «Проверить», «Запустить» → ✓ Поисковые запросы. Первый скан идёт несколько минут.
5. Telegram: написать боту `/start`, «Определить chat_id», «Тестовое сообщение» → ✓ Telegram.

## 4. Claude Code и разбор вакансий

- Разбор и письма делает Claude через `/hh-batch` в сеансе Claude Code в папке проекта — покажи, как запустить:
  открыть Claude Code в папке панели и написать `/hh-batch`. Ключ Anthropic API не нужен и не используется.
- Автономный разбор: `claude` → `/login` в обычном терминале (делает человек), затем `CLAUDE_CLI_AUTORUN=true`
  в `.env` и перезапуск панели. `doctor` покажет «Claude Code в PATH» и «Автономный разбор».

## 5. Постоянная работа

- Windows: `.\run.ps1 autostart` — задача планировщика, панель стартует при входе. `doctor` → ✓ Автозапуск.
  Ярлык на рабочий стол: `.\run.ps1 shortcut` (двойной клик открывает панель, запуская её при необходимости).
- Linux/macOS: systemd user unit или launchd с командой `backend/.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000`
  из папки `backend`. Постоянная работа на Linux-сервере (системная служба, туннель с ноутбука, обновление, копии) —
  README, раздел «Работа на сервере».
- Необязательно, но полезно: `IMAP_USER`/`IMAP_PASSWORD` (пароль приложения Gmail) — письма hh.ru про
  просмотры, приглашения и отказы сами попадут в журнал ответов.
- Необязательно: страница «Каналы» — публичные Telegram-каналы с вакансиями (`@имя`); новые посты придут в бота.

## 6. Финал

`.\run.ps1 doctor --json` → `"ready": true` и пустой `next_steps` (кроме необязательных). Расскажи человеку
ежедневный цикл: сканер → пакет → `/hh-batch` → «Вакансии» или «Воронка» → отклик → журнал ответов (README,
«Первый запуск» и «Разбор в Claude Code»). Если что-то не сходится — `logs/` и README (раздел «Подводные камни»).
