# Job Search Panel и Claude Code

## Установка у нового пользователя

Если панель скачали из репозитория и просят «установи», «настрой», «запусти», выполняй команду `/setup`
(`.claude/commands/setup.md`). Она ведёт по шагам и проверяет состояние через `.\run.ps1 doctor`.

Секреты (ключи приложения hh.ru, токен бота, пароли) вводит человек сам. Ты объясняешь, где их взять, и проверяешь
результат через `doctor`, не запрашивая и не выводя значения.

## Разбор вакансий

Оценки и сопроводительные письма делает Claude в сеансе Claude Code командой `/hh-batch`
(`.claude/commands/hh-batch.md`): панель кладёт пакеты в `data/exchange/pending/`, результат пишется в
`data/exchange/done/`. Правила разбора — `data/exchange/guidelines.md`, профиль кандидата — `data/exchange/profile.md`.

## Ограничения

- Не добавлять вызовы LLM-API: оценка и письма делаются только в сеансе Claude Code.
- Не использовать чужие `client_id`, не эмулировать браузер, не обходить капчу и лимиты hh.ru.
- Секреты только в `.env`, он не попадает в git.
- Если панель работает на Linux-сервере (`.panel-remote.json` с `panel_on_server: true`), не запускать её на этом
  компьютере с рабочими `.env` и базой: два экземпляра отзывают друг у друга токен приложения hh.ru и делят
  `getUpdates` бота. Подробности — README, «Работа на сервере».
